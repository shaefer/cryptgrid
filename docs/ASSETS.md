# ASSETS.md — Asset Strategy

**Wave 1 (Milestone 0): 100% generated in-repo.** Zero external dependencies, zero license risk, ships today. DM-authentic look = good tileable *textures* on simple geometry; the geometry was never the point.

## Provenance rules

- Every file under `assets/` must be listed in the manifest table at the bottom of this doc with its origin: `generated:<script>` or `CC0:<source url>`.
- Allowed origins: generated by our scripts, or CC0 (Kenney, Quaternius, OpenGameArt-CC0). Nothing else. No AI-generated *copies of identifiable existing game art*; prompts/scripts must aim at generic dark-fantasy stonework.

## Wave 1: procedural texture generator

`tools/gen-textures/` — a Node script (node-canvas) producing 512×512 tileable PNGs into `assets/textures/`. Deterministic (seeded) so regeneration is reproducible; committed outputs are the source of truth for builds.

Technique per texture — layered and cheap but effective:
1. Base coat: two-tone noise (value noise, seeded) in the palette below.
2. **Brick/block pattern:** offset courses of rectangles with 4–6px dark mortar gaps; per-brick value jitter ±8%; 1px highlight top edge / shadow bottom edge for fake relief.
3. Grunge pass: low-opacity splotch noise + a few cracks (random walk lines).
4. Wrap-check: script renders each texture 2×2 tiled into `assets/textures/_preview/` — eyeball these; seams are the #1 quality killer.

## Wave 1: item sprites & rune glyphs

- **Items** (`assets/items/*.png`, 128×128, transparent): shortsword, torch, bread, waterflask, ironkey, scroll. Options in order of preference: (a) generated by `tools/gen-items/` as stylized flat-shaded canvas drawings — a chunky readable "painted icon" style is very achievable programmatically; (b) CC0 icon sets (Kenney's game icons) as stopgap. Don't stall M0 on beauty — colored placeholder silhouettes are acceptable for the first commit.
- **Rune glyphs** (`assets/runes/*.svg`, 24 files): generated by `tools/gen-runes/` — seeded angular single-stroke paths on a 64×64 grid (3–6 segments, chisel-cut aesthetic, mirrored variants forbidden to avoid confusion). Hand-tweak any that read badly. SVG so the HUD can tint them (unlit / lit / insufficient-mana states via CSS).

## Wave 2 (post-M0, optional)

- Kenney CC0 modular 3D kits (e.g., their dungeon/graveyard kits) for props: barrels, chains, bones, braziers — set dressing on top of our textured shell, not a replacement for it.
- Audio: jsfxr/generated SFX for steps, thud, door grind, rune press, fizzle, firebolt; CC0 ambience loop. (M0 may ship silent; add SFX the moment the loop feels good — sound is half the DM mood.)
