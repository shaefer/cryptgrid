# Cryptgrid: Vault of Shadows

A first-person, real-time, grid-based dungeon crawler in the tradition of Dungeon Master and Legend of Grimrock — built for the web with Three.js + TypeScript, with a multiplayer-ready authoritative simulation at its core.

**Status:** Milestone 0 — see [`docs/ROADMAP.md`](docs/ROADMAP.md).
